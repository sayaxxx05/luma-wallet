# Luma Wallet · Advanced Software — Midterm + Final

Учебный Web3-проект на русском языке: **платёжный интерфейс для Ethereum-кошелька MetaMask**. Отличающийся от cyberpunk минималистичный стиль, адаптация под телефон.

## Функции

- Главная панель с ETH-балансом, сетью, показателями и историей.
- Подключение MetaMask (EIP-1193), Ethereum Mainnet и Sepolia Testnet.
- Отправка нативного ETH с подтверждением в MetaMask, проверка адреса и точности суммы.
- Получение адреса / QR, копирование ссылки и **ссылка на запрос оплаты с суммой**.
- Статусы исходящих транзакций (`pending`, `success`, `failed`).
- Деморежим с учебным балансом 2.845 ETH, без реального блокчейна.
- Архитектура с отдельными классами для SOLID: см. `wallet-core.js` и `docs/SOLID_Explanation.md`.

## Запуск

Скачайте ZIP, распакуйте и откройте `index.html` в Chrome (деморежим). Для расширения MetaMask предпочтительнее HTTPS, получаемый после публикации.

```bash
python -m http.server 8000
```

Сайт появится по адресу `http://localhost:8000` (на вашем ПК).

### Тесты

```bash
node --test tests/core.test.js
```

Отдельный скрипт `tests/browser_smoke.py` предназначен для локального запуска с Playwright/Chromium; в окружении подготовки проекта запуск навигации Chromium ограничен системой, поэтому не выдаётся за успешно пройденный end-to-end тест.

## Ограничения безопасности

- Учебное приложение НЕ хранит приватные ключи, seed phrases, пароли или средства.
- Для экспериментов рекомендуется Sepolia. Реальный Ethereum Mainnet приводит к необратимому переводу денег и сетевой комиссии.
- QR содержит публичный адрес, не приватные ключи.
- Платёжная ссылка — лишь заранее заполненная форма, **не подтверждение фактической оплаты**.
- История содержит только операции, сделанные в этом приложении и браузере; нет полной истории цепочки или интеграции бухгалтерии предприятия.
- Чтобы выполнить пункт «развёрнуто в облаке», необходимо выполнить DEPLOY_RENDER.md и предоставить действующий публичный URL. Конфиг готов, деплой не выполнен автоматически.
