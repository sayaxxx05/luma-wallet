# Luma Wallet — Crypto Payment System

## Project Description
Luma Wallet is a web-based cryptocurrency payment system designed to provide a simple, secure, and user-friendly interface for managing cryptocurrency transactions.

## Main Features
- MetaMask wallet integration
- View cryptocurrency balance
- Send and receive ETH
- Transaction history
- QR code for receiving payments
- Demo mode for testing

## Technologies
- HTML, CSS, JavaScript
- MetaMask and Ethereum
- GitHub Pages for cloud hosting

## Software Architecture
The project demonstrates object-oriented programming concepts and SOLID principles through modular components.

## Documentation
The project includes technical specifications, UML diagrams, architecture documentation, and testing materials.

## Purpose
This project was developed as part of the Advanced Software Development course.
